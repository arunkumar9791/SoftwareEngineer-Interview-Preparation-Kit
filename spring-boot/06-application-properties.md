# Application Properties

It is a configuration file used to control how Spring Boot application behaves, without changing Java code.

It defines how application is configured.

| | |
|---|---|
| `pom.xml` | declares which libraries are available. |
| `application.properties` | configures how application behaves. |

**application.properties**

```properties
spring.application.name=employee-management
server.port=8080
spring.datasource.url=jdbc:mysql://localhost:3306/employee_db
spring.datasource.username=${DB_USERNAME}
spring.datasource.password=${DB_PASSWORD}

# asks Hibernate to update DB schema
spring.jpa.hibernate.ddl-auto=update

# displays SQL statements generated by Hibernate log.
spring.jpa.show-sql=true
```

## Creating own properties in application.properties

```properties
company.name=ABC Technologies
employee.default-age=25
```

You can access them from Spring-Managed Java class using `@Value`;

```java
@Component
public class CompanyInfo
{
    @Value("${company.name}")
    private String companyName;

    public void display()
    {
        System.out.println(companyName);
    }
}
```
