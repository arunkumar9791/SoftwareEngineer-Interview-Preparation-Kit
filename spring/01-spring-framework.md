# Spring

## Spring Framework

Spring Framework is an open-source Java framework for building applications in Java.

It builds application easily by managing objects, connecting components and reducing amount of code we need to write.

## Core Concepts of Spring

Spring main goal is to make Java Development loosely coupled.

```
- Inversion of Control (IOC)  ┐
                              ├ core concepts
- Dependency Injection (DI)   ┘

- Spring Beans

- IOC Container (Bean Factory & Application Context)

- Aspect Oriented Programming
```
